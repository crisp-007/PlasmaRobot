# 整机流程主任务

更新时间：2026-07-23

## 主目标

当前唯一主线是将已有模块整合成操作者可以顺序完成的一套整机流程：

```text
系统自检
-> 相机采集
-> 残腔重建与术区选择
-> 路径规划
-> 机械臂执行
-> 等离子处理
-> 处理完成/安全复位
```

真实机械臂连接自检和完整手眼坐标变换的软件框架已经完成，L515 暂用手眼矩阵也已接入。当前等待严格矩阵验收和真实等离子喷枪 TCP；在两项标定完成并验收前，只允许坐标预览，不允许自动执行转换后的路径。此前“人工对准入口 + 工具坐标分层 + J6 左右半圈”仍只作为低速断电演示方案，不能替代正式路径执行。

当前优先级：

```text
已接入 L515 暂用手眼矩阵
-> 完成非接触验证/严格验收
-> 确认真实喷枪 TCP与末端 URDF
-> 已知点转换验收
-> 输出入口后的连续 TCP/法兰位姿
-> 输出每个点的运动阶段与喷涂开关
-> 等离子安全联锁
```

范围边界：软件不规划或控制机械臂从初始位置到腔口/喷涂入口的运动。输出路径的第一个点就是入口后的喷涂起始位姿，下游只消费这个点及其后的喷涂轨迹。

目录边界：机械臂手眼工具统一放在 `src/third_party/plasma_robot/tools/eye_hand/`，TF 与坐标转换工具统一放在 `src/third_party/plasma_robot/tools/tf/`。共享消息包 `plasma_robot_interfaces` 保持独立。L515 暂用矩阵已经接入，TF 包已经迁移；严格验收和真实喷枪 TCP 完成前仍不可执行。

## 中断恢复规则

- 本文档记录的是当前最高优先级任务。后续工作因上下文切换、构建失败、程序退出或工具会话结束而中断时，必须从最后一个未完成项继续，不能跳到其他功能。
- 恢复工作时先检查本文档、`HANDOFF.md`、工作区修改、最近构建结果和正在运行的 ROS/GUI 进程。
- 只有经过代码检查、构建和对应级别验证的项目才能标记完成。
- 不得把临时演示动作描述为自动规划轨迹；界面和日志必须明确当前采用人工入口对准和相对分层运动。

## 当前基础

- 系统自检可以检查并自动启动相机。
- 已有实时点云暂停/恢复、关键帧裁剪和关键帧保存。

- RealMan ECO65-BI 驱动、`/joint_states`、MoveJ 和工具坐标 MoveL 已接通。
- 系统自检已正式接入 `rm_driver/rm_eco65_driver.launch.py`，同时验证 `/rm_driver` 和实时六关节状态，15 秒超时。
- 正式 GUI 中已完成一次自动启动相机与真实机械臂驱动的完整自检，结果通过；未发送运动命令。
- `plasma_robot_interfaces` 保持独立；`plasma_eye_hand` 和 `plasma_path_transform` 已分别整理到 `tools/eye_hand/` 和 `tools/tf/`。
- GUI 会冻结采集时 `frame_id`、时间戳和六关节状态，并发布相机坐标系路径。
- 转换链固定为 `T_base_gripper(capture) * T_gripper_camera * T_camera_tcp`；缺少手眼矩阵时拒绝转换。
- 默认加载 L515 `f1423110` 的 HORAUD 暂用矩阵；未验收标定只能输出 `execution_permitted=false` 的预览。
- 当前控制器工具系实机确认是 `Arm_Tip`，工具 `+Z` 朝喷嘴尖端方向。
- `ArmRosAdapter` 已封装 MoveJ、工具坐标 MoveL、停止和当前工具系查询。

```text

```

- 速度固定为 5%，任一步失败或超时会发送停止命令。
- 实机已验证单层旋转，以及沿工具 `+Z` 每层 5 mm 的三层演示。
- 临时脚本位于：
  - `src/plasma_gui/scripts/single_layer_rotation_demo.py`
  - `src/plasma_gui/scripts/multi_layer_rotation_demo.py`

### 等离子

- 主窗口已有气体模式、流量、比例、启动/停止、计时和串口控制界面。
- `Serial::setPlasmaControl(...)` 和 `Serial::emergencyStop()` 已存在。
- 当前等离子控制仍是独立手动页面，没有与机械臂运动阶段形成状态机联锁。
- 机械臂演示执行器中的“喷涂开启/关闭”目前仅写日志，真实等离子输出保持关闭。

## 当前结构问题

1. L515 暂用手眼矩阵已加载，但严格离线验收未通过，只能生成不可执行预览。
2. 当前旧 TCP 可能属于旧笔尖，真实等离子喷枪 TCP 尚未确认。
3. 实测标定完成后，尚需核对转换后的 TCP/法兰位姿、运动阶段和喷涂开关是否与规划路径一致。
4. 系统自检已检查相机和机械臂，但还没有正式的等离子串口/控制器健康检查。
5. 等离子开关没有受机械臂执行阶段、故障状态和急停状态完整约束。
6. GUI 内仍有两个同名 `/plasma_gui_node`，会产生 rosout publisher 警告，后续需单独整理命名。

## 完成定义

机械臂融合阶段只有同时满足以下条件才算完成：

- 操作者能按向导从路径规划进入独立机械臂执行步骤。
- 未选择有效轨迹、机械臂离线或工具轴未验证时不能启动。
- GUI 内可以完成单层和多层干运行，不依赖终端脚本。
- 页面实时显示层号、动作阶段、进度、成功/失败和停止状态。
- 急停能够停止机械臂，并保证等离子输出处于关闭状态。
- 构建通过，模拟流程通过，实机低速干运行通过。
