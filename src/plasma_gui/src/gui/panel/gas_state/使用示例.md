# 气体状态控件使用示例

## FlowDisplayWidget 流量显示控件

### 基础使用
```cpp
// 创建控件
FlowDisplayWidget* flowWidget = new FlowDisplayWidget(parent);

// 设置流量值
flowWidget->SetFlowValue("15.5 L/min");
flowWidget->SetFlowValue(15.5, "L/min");
flowWidget->SetFlowValueWithFormat(15.5, "%.1f L/min");
```

### 样式设置
```cpp
// 设置文本样式
flowWidget->SetTextColor(QColor(255, 255, 255));
flowWidget->SetTextSize(14);
flowWidget->SetTextStyle(QColor(255, 255, 255), 14, true);

// 设置背景样式
flowWidget->SetBackgroundGradient(QColor(0, 100, 200), QColor(0, 150, 255));
flowWidget->SetBackgroundStyle(QColor(0, 100, 200), QColor(0, 150, 255), QColor(100, 100, 100));
```

### 动画控制
```cpp
// 设置动画
flowWidget->SetAnimationDuration(1500);
flowWidget->SetAnimationEnabled(true);
```

### 预设主题
```cpp
// 应用预设主题
flowWidget->ApplyBlueTheme();    // 蓝色主题
flowWidget->ApplyGreenTheme();   // 绿色主题
flowWidget->ApplyOrangeTheme();  // 橙色主题
flowWidget->ApplyRedTheme();     // 红色主题
```

### 完整示例
```cpp
// 完整的He气体流量显示
FlowDisplayWidget* heFlowWidget = new FlowDisplayWidget(parent);
heFlowWidget->ApplyBlueTheme();
heFlowWidget->SetFlowValue(8.2, "L/min");
heFlowWidget->SetAnimationDuration(1200);

// 完整的Ar气体流量显示
FlowDisplayWidget* arFlowWidget = new FlowDisplayWidget(parent);
arFlowWidget->ApplyGreenTheme();
arFlowWidget->SetFlowValue(7.3, "L/min");
arFlowWidget->SetAnimationEnabled(false);
```

## GasProgressWidget 气体进度条控件

### 基础使用
```cpp
// 创建控件
GasProgressWidget* gasWidget = new GasProgressWidget(parent);

// 设置数值
gasWidget->SetValue(75);
gasWidget->SetValueWithRange(75, 0, 100);
gasWidget->SetPercentage(75.0);
```

### 样式设置
```cpp
// 设置颜色
gasWidget->SetProgressColor(QColor(33, 150, 243));
gasWidget->SetBackgroundColor(QColor(51, 51, 51));
gasWidget->SetBorderColor(QColor(85, 85, 85));
gasWidget->SetCornerRadius(10);

// 一次设置完整样式
gasWidget->SetFullStyle(QColor(33, 150, 243), QColor(51, 51, 51), QColor(85, 85, 85), 10);

// 设置尺寸
gasWidget->SetSize(20, 100);
```

### 预设样式
```cpp
// 应用预设样式
gasWidget->ApplyHeGasStyle();      // He气样式（蓝色）
gasWidget->ApplyArGasStyle();      // Ar气样式（绿色）
gasWidget->ApplyWarningStyle();    // 警告样式（橙色）
gasWidget->ApplyNormalStyle();     // 正常样式（绿色）
```

### 气体状态管理
```cpp
// 一次设置气体状态（压力、容量、流量、比例）
gasWidget->SetGasStatus(12.5, 75, 8.2, 53);

// 设置低容量警告
gasWidget->SetLowVolumeWarning(true, 20);  // 启用警告，阈值20%
```

### 状态查询
```cpp
// 查询状态
double percentage = gasWidget->GetPercentage();
bool isLow = gasWidget->IsLowVolume();
bool isEmpty = gasWidget->IsEmpty();
QString status = gasWidget->GetStatusText();
QString volumeStatus = gasWidget->GetVolumeStatusText();
```

### 完整使用示例
```cpp
// He气体进度条控件
GasProgressWidget* heProgressBar = new GasProgressWidget(parent);
heProgressBar->ApplyHeGasStyle();
heProgressBar->SetGasStatus(12.5, 75, 8.2, 53);
heProgressBar->SetLowVolumeWarning(true, 20);

// Ar气体进度条控件
GasProgressWidget* arProgressBar = new GasProgressWidget(parent);
arProgressBar->ApplyArGasStyle();
arProgressBar->SetGasStatus(8.3, 45, 7.3, 47);
arProgressBar->SetLowVolumeWarning(true, 15);

// 检查状态
if (heProgressBar->IsLowVolume()) {
    qDebug() << "He气体容量不足:" << heProgressBar->GetVolumeStatusText();
}
```

## 在MainWindow中的使用建议

### 替换原有的复杂创建代码
```cpp
// 原来的代码（复杂）
void MainWindow::SetupGasStatusDisplay()
{
    // 创建流量显示FlowDisplayWidget
    flow_display_widget = new FlowDisplayWidget(ui->gasStatusWidget);
    flow_display_widget->SetFlowValue("15.5 L/min");
    // ... 更多的参数设置代码 ...
    
    // 创建He气体进度条
    he_progress_bar = new GasProgressWidget(ui->gasStatusWidget);
    he_progress_bar->SetProgressColor(QColor(33, 150, 243));
    he_progress_bar->SetValue(75);
    // ... 更多的参数设置代码 ...
}

// 新的代码（简洁）- 推荐使用Qt Designer设计控件
void MainWindow::SetupGasStatusDisplay()
{
    // 直接操作界面上的控件
    ui->flowDisplayWidget->ApplyBlueTheme();
    ui->flowDisplayWidget->SetFlowValue(15.5, "L/min");
    
    ui->heProgressWidget->ApplyHeGasStyle();
    ui->heProgressWidget->SetGasStatus(12.5, 75, 8.2, 53);
    
    ui->arProgressWidget->ApplyArGasStyle();
    ui->arProgressWidget->SetGasStatus(8.3, 45, 7.3, 47);
}
```

### 动态更新示例
```cpp
void MainWindow::UpdateGasStatus()
{
    // 更新流量显示
    ui->flowDisplayWidget->SetFlowValue(getCurrentFlowRate(), "L/min");
    
    // 更新He气状态
    ui->heProgressWidget->SetGasStatus(
        getHePressure(),
        getHeVolume(),
        getHeFlowRate(),
        getHeRatio()
    );
    
    // 检查气体状态
    if (ui->heProgressWidget->IsLowVolume()) {
        showWarning("He气体容量不足");
    }
}
```

## 优化效果

1. **代码简洁**：复杂的创建代码变为一行调用
2. **类型安全**：避免了字符串拼接和格式化错误
3. **功能丰富**：提供了更多数据的管理选项
4. **便于维护**：统一的接口方法，便于后期修改
5. **预设主题**：快速应用常用的样式配置
