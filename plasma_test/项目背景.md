# 等离子设备控制板项目背景说明

## 1. 项目概述

本项目面向一套以氦气或氩气作为工作气体的等离子设备。设备需要在受控气体流量和受控供电条件下产生稳定的高压等离子体，因此系统同时涉及：

- 氦气、氩气两路气体供应；
- 气源压力监测；
- 气路通断控制；
- 气体流量设定与反馈；
- 交流调压；
- 等离子电源控制；
- 高压输出反馈采集；
- 运行状态监测和安全联锁。

本控制板是整套设备的核心控制单元，主要负责采集各类传感器数据、控制气路和电源执行机构，并协调气体供应、调压和等离子输出之间的工作顺序。

控制板的核心目标不是单独控制某一个器件，而是保证设备按照安全、可控的流程完成：

```text
气源检查
→ 气路开启
→ 流量建立
→ 调压器调节
→ 等离子电源启动
→ 高压反馈监测
→ 稳定运行
```

## 2. 系统总体组成

整套等离子设备主要由以下部分组成：

1. 氦气气路；
2. 氩气气路；
3. 两路压力传感器；
4. 两路常闭电磁阀；
5. 两路 MFC 质量流量控制器；
6. 调压器；
7. 步进电机及其驱动器；
8. 等离子电源；
9. 等离子发生装置；
10. STM32 控制板。

系统可以划分为气路系统和等离子供电系统两部分。

```text
气路系统：

氦气瓶 → 氦气压力传感器 → 氦气电磁阀 → 氦气 MFC ┐
                                                        ├→ 等离子装置
氩气瓶 → 氩气压力传感器 → 氩气电磁阀 → 氩气 MFC ┘


供电系统：

220 V 市电 → 调压器 → 等离子电源 → 高压导线 → 等离子装置
                  ↑          ↓
            步进电机调节   高压反馈信号
                  ↑          ↓
                  └──── 控制板 ────┘
```

## 3. 两路气体供应系统

设备包含两路相互独立的工作气体：

- 氦气 He；
- 氩气 Ar。

两路气体采用基本相同的硬件结构：

```text
气瓶
→ 压力传感器
→ 常闭电磁阀
→ MFC 质量流量控制器
→ 等离子装置
```

控制板需要分别管理两路气体，不能把氦气和氩气通道当作同一个控制对象。

### 3.1 压力传感器

每路气体首先经过一个压力传感器。压力传感器通过 RS485 与控制板通信，并上传当前气体压力值。

压力数据主要用于：

- 显示氦气和氩气的当前供气压力；
- 判断气瓶是否已经连接；
- 判断气源压力是否满足设备启动条件；
- 粗略反映气体剩余情况；
- 检测气源压力过低、断气或压力异常；
- 作为等离子设备的安全联锁条件。

压力传感器反映的是气源侧的供气状态，并不直接负责精确控制气体流量。

系统中至少存在两个独立的压力对象：

```text
氦气压力
氩气压力
```

控制软件需要分别保存它们的实时值、通信状态、报警状态和更新时间。

### 3.2 气体电磁阀

压力传感器之后是气体电磁阀，用于控制对应气路的整体通断。

电磁阀特性如下：

- 默认状态为常闭；
- 不供电时气路关闭；
- 通入 24 V 后电磁阀开启；
- 氦气和氩气分别使用独立的电磁阀。

其控制逻辑可以表示为：

```text
24 V 断开 → 电磁阀关闭 → 气路截止
24 V 接通 → 电磁阀开启 → 气体允许通过
```

电磁阀属于安全执行器。设备上电、MCU 复位、程序异常、通信中断或紧急停机时，电磁阀都应回到关闭状态。

### 3.3 MFC 质量流量控制器

电磁阀之后是 MFC（Mass Flow Controller，质量流量控制器）。MFC 用于精确设定并监测实际进入等离子装置的气体流量。

控制板对每路 MFC 提供三类功能：

1. 通过继电器控制 MFC 上电和断电；
2. 通过模拟量输出设置目标流量；
3. 通过模拟量输入读取实际流量反馈。

单路 MFC 的控制关系为：

```text
控制板继电器输出 → MFC 电源通断
控制板 DAC 输出  → MFC 目标流量设定
控制板 ADC 输入  ← MFC 实际流量反馈
```

两路 MFC 分别对应氦气和氩气：

| 气路 | MFC 电源 | 流量设定 | 流量反馈 |
|---|---|---|---|
| 氦气 | 继电器控制 | 模拟量输出 | 模拟量输入 |
| 氩气 | 继电器控制 | 模拟量输出 | 模拟量输入 |

从功能上看，气路中的三个器件各自承担不同职责：

- 压力传感器：判断气源是否正常；
- 电磁阀：控制整条气路是否导通；
- MFC：精确控制和反馈气体流量。

## 4. 调压器系统

调压器的输入为 220 V 交流市电，输出为可调的 0～220 V 交流电。调压器输出作为等离子电源的输入电压，用来调节等离子电源的供电水平。

调压器不是通过数字通信直接设定输出电压，而是通过机械手柄调整。系统在调压器手柄上安装步进电机，由步进电机转动手柄改变输出电压。

控制路径为：

```text
控制板
→ RS485
→ 步进电机驱动器
→ 步进电机
→ 调压器手柄
→ 改变调压器输出电压
```

控制板同时具有调压器输出电压采集接口，用于测量调压器当前输出的 0～220 V 交流电压。

因此，调压过程应形成基于电压反馈的调节流程：

```text
设置目标电压
→ 采集当前输出电压
→ 计算目标值与当前值的偏差
→ 控制步进电机正转或反转
→ 再次采集输出电压
→ 达到允许误差后停止电机
```

调压器控制应考虑：

- 调节方向；
- 电机转速；
- 单次运行时间；
- 输出电压上限；
- 目标电压允许误差；
- 机械行程限制；
- 电机堵转或调节无效检测；
- 交流采样的滤波和有效值计算。

## 5. 等离子电源系统

等离子电源接收调压器输出的交流电，并产生等离子装置所需的高压。高压通过专用高压导线传输到等离子发生装置。

供电关系为：

```text
220 V 市电
→ 调压器输出 0～220 V AC
→ 等离子电源
→ 高压输出
→ 等离子装置
```

调压器改变等离子电源的输入电压，从而影响等离子电源最终的高压输出。

### 5.1 高压反馈

等离子电源提供高压反馈接口。反馈接口输出与实际高压成比例的正弦波信号：

```text
反馈范围：-30 V～+30 V
换算关系：反馈 1 V 对应实际高压 1 kV
```

例如：

| 反馈信号峰值 | 对应的实际高压峰值 |
|---:|---:|
| 5 V | 5 kV |
| 10 V | 10 kV |
| 20 V | 20 kV |
| 30 V | 30 kV |

控制板上的采集电路负责将 `-30～+30 V` 的双极性反馈信号缩放并偏置到 STM32 ADC 可以采集的范围。

原理图中的目标形式为：

```text
ADC 输入 = 1.67 V + 双极性交流分量
```

经过调理后：

- 原反馈为 0 V 时，ADC 输入约为 1.67 V；
- 原反馈为正峰值时，ADC 输入接近 3.3 V；
- 原反馈为负峰值时，ADC 输入接近 0 V。

软件需要完成：

1. ADC 波形采样；
2. 去除约 1.67 V 的直流偏置；
3. 根据硬件分压和放大系数恢复反馈电压；
4. 根据 `1 V = 1 kV` 换算实际高压；
5. 计算峰值、峰峰值、频率或有效值；
6. 判断等离子电源是否正常输出；
7. 检测过压、欠压和波形异常。

## 6. 控制板在系统中的职责

控制板是设备各个子系统之间的协调中心，主要承担以下职责。

### 6.1 数据采集

- 通过 RS485 读取氦气压力；
- 通过 RS485 读取氩气压力；
- 读取两路 MFC 实际流量模拟反馈；
- 采集调压器 0～220 V 输出电压；
- 采集等离子电源 `-30～+30 V` 高压反馈波形；
- 采集其他开关量和设备状态。

### 6.2 执行控制

- 控制氦气电磁阀；
- 控制氩气电磁阀；
- 控制两路 MFC 上电和断电；
- 设置氦气 MFC 目标流量；
- 设置氩气 MFC 目标流量；
- 通过 RS485 控制步进电机驱动器；
- 调节调压器输出电压；
- 控制等离子电源的工作状态；
- 控制状态灯、蜂鸣器和风扇。

### 6.3 状态管理

- 维护设备待机、准备、运行、停机和故障状态；
- 判断气源、流量、调压和高压反馈是否正常；
- 按照既定顺序启动和停止设备；
- 在出现异常时执行安全停机；
- 向上位机或人机界面上传实时数据和报警信息。

## 7. 典型工作流程

### 7.1 启动流程

设备启动时应按顺序建立工作条件：

```text
1. 控制板上电并完成自检
2. 所有电磁阀保持关闭
3. MFC 流量设定为 0
4. 等离子电源保持关闭
5. 检查氦气和氩气压力传感器通信
6. 判断气源压力是否满足要求
7. 给需要使用的 MFC 上电
8. 设置目标气体流量
9. 打开对应气体电磁阀
10. 确认 MFC 实际流量达到要求
11. 控制步进电机调节调压器
12. 确认调压器输出电压达到目标
13. 启动等离子电源
14. 采集并检查高压反馈波形
15. 进入正常运行状态
```

只有当前一步满足条件后，系统才允许执行下一步。

### 7.2 正常停机流程

正常停机应按与启动大致相反的顺序进行：

```text
1. 停止等离子高压输出
2. 控制调压器降低输出电压
3. 将 MFC 流量设定为 0
4. 关闭氦气和氩气电磁阀
5. MFC 下电
6. 保存运行记录并进入待机状态
```

### 7.3 故障停机

发生严重故障时，应优先保证人员和设备安全：

```text
立即停止等离子高压输出
→ 停止调压电机
→ MFC 设定归零
→ 关闭气体电磁阀
→ 记录故障原因
→ 进入故障锁定状态
```

典型故障包括：

- 气源压力过低；
- 压力传感器 RS485 通信超时；
- MFC 实际流量与设定值偏差过大；
- 调压器输出过高；
- 步进电机动作后电压没有变化；
- 高压反馈过高、过低或波形异常；
- ADC 采样异常；
- 电源或执行器状态异常；
- 急停信号触发。

## 8. 软件设计需要理解的业务对象

软件中建议将设备拆分为以下业务对象：

| 业务对象 | 主要数据 | 主要操作 |
|---|---|---|
| 氦气压力传感器 | 当前压力、通信状态、报警状态 | 查询压力、判断气源 |
| 氩气压力传感器 | 当前压力、通信状态、报警状态 | 查询压力、判断气源 |
| 氦气电磁阀 | 开关状态 | 开启、关闭 |
| 氩气电磁阀 | 开关状态 | 开启、关闭 |
| 氦气 MFC | 目标流量、实际流量、电源状态 | 上电、下电、设定、读取 |
| 氩气 MFC | 目标流量、实际流量、电源状态 | 上电、下电、设定、读取 |
| 调压器 | 目标电压、实际电压、调节状态 | 升压、降压、停止 |
| 步进电机驱动器 | 通信状态、方向、速度、运行状态 | RS485 指令控制 |
| 等离子电源 | 启停状态、高压反馈、故障状态 | 启动、停止、监测 |
| 系统控制器 | 当前流程、联锁条件、故障信息 | 状态切换和流程协调 |

硬件驱动只负责 GPIO、UART、ADC、DAC 等底层操作；气路开启、流量建立、调压和高压启动顺序应由上层设备状态机统一管理。

## 9. 项目特点

本项目不是单纯的数据采集板或通用 STM32 控制板，而是一套同时包含以下功能的等离子设备主控制系统：

- 两路气体供应管理；
- RS485 传感器通信；
- 24 V 电磁阀控制；
- MFC 模拟量设定与反馈；
- 交流电压采集；
- 步进电机闭环调压；
- 等离子高压输出反馈采集；
- 多设备时序控制；
- 安全联锁与故障停机。

该控制板的软件设计重点不仅是完成各个外设驱动，还需要保证不同子系统之间的启动顺序、停止顺序、联锁条件和故障处理逻辑正确。

## 10. 项目总体目标

本项目最终需要实现：

1. 实时监测氦气和氩气气源状态；
2. 安全控制两路气体通断；
3. 精确设置并读取两路气体流量；
4. 自动调节等离子电源输入电压；
5. 实时采集等离子高压反馈；
6. 保证气体、调压和高压输出按照正确顺序运行；
7. 在任何关键条件异常时快速进入安全状态；
8. 为上位机提供清晰的实时数据、设备状态和故障信息。

简而言之，本控制板承担的是：

> 对气源、流量、调压器和等离子电源进行统一协调，使等离子设备能够在气体供应正常、流量稳定、电压可控并具有安全保护的条件下运行。
