# 等离子设备控制板当前代码引脚分配说明

> 本文档结合 `板子资源.md`、`项目背景.md` 以及当前 `plasma_test` 工程代码整理。  
> 目标是记录当前固件已经实际接入的板卡资源、业务含义、控制协议和安全默认状态，方便后续继续开发、接线核对和上位机联调。

## 1. 项目背景

本项目面向一套等离子设备控制系统。设备以氦气或氩气作为工作气体，在受控气体流量和受控供电条件下产生稳定的等离子体。

控制板当前承担的核心职责包括：

- 管理氦气、氩气两路气体通路；
- 控制两路 MFC/流量控制器的供电通断；
- 控制两路气体电磁阀的开启和关闭；
- 控制调压器继电器和等离子电源继电器；
- 读取调压器初始位置、最大位置两个限位开关；
- 通过 USART1/CH340 接收调试命令，并输出操作者可读状态日志；
- 通过 USART6/485-2 接收上位机命令，并回传 28 字节二进制状态包。

设备典型业务链路为：

```text
气源检查 -> MFC 上电 -> 气体电磁阀打开 -> 流量建立
-> 调压器调整 -> 等离子电源启动 -> 运行状态监控
```

当前代码还处于底层资源接入和联调阶段，已经完成继电器、气阀、限位输入、串口命令和状态日志的基础框架。

## 4. 气体通路分配

### 4.1 氦气通路

氦气通路当前由两类执行器控制：

| 功能 | 代码别名 | 引脚 | 业务说明 |
|---|---|---|---|
| 氦气 MFC/流量控制器供电 | `He_MFC` | PC3 | 控制当前有效 MFC 通道上下电，SWRAY2 |
| 氦气气路电磁阀 | `he_valve` | PD12 | 输出开启后外部通 24V，氦气阀打开 |

氦气控制关系：

```text
He_MFC = POWER_ON -> 当前有效 MFC/流量控制器上电
he_valve = ON  -> 氦气电磁阀得电，气路打开
he_valve = OFF -> 氦气电磁阀断电，气路关闭
```

### 4.2 氩气通路

氩气通路当前同样由两类执行器控制：

| 功能 | 代码别名 | 引脚 | 业务说明 |
|---|---|---|---|
| 氩气 MFC/流量控制器供电 | `Ar_MFC` | PC2 | 原理图对应 SWRAY1，但当前硬件接线存在问题，代码暂时禁用 |
| 氩气气路电磁阀 | `ar_valve` | PD13 | 输出开启后外部通 24V，氩气阀打开 |

氩气控制关系：

```text
Ar_MFC = DISABLED -> 当前禁用，不响应上电和流量设定
ar_valve = ON  -> 氩气电磁阀得电，气路打开
ar_valve = OFF -> 氩气电磁阀断电，气路关闭
```

### 4.3 备用气阀输出

| 代码别名 | 板子网络 | 引脚 | 当前用途 |
|---|---|---|---|
| `spare_valve_3` | GOU3_1 | PD14 | 备用，初始化关闭 |
| `spare_valve_4` | GOU4_1 | PD15 | 备用，初始化关闭 |

当前协议没有给 `spare_valve_3`、`spare_valve_4` 分配命令位。

## 6. 串口协议与命令映射

### 6.1 命令包格式

USART1 和 USART6 都接收同一套 16 字节二进制命令包：

| 字节位置 | 字段 | 类型 | 说明 |
|---|---|---|---|
| 0-1 | `header` | uint16_t | 固定 `0xFEFF`，小端发送为 `FF FE` |
| 2 | `EmerStop` | uint8_t | 急停标志，非 0 触发全部关闭 |
| 3 | `VolRelay` | uint8_t | 等离子电源/调压器继电器控制 |
| 4-5 | `VolOutValue` | uint16_t | 预留电压输出/设定值 |
| 6 | `HeFLOWRelay` | uint8_t | 氦气 MFC 继电器和氦气阀控制 |
| 7-8 | `HeOutValue` | uint16_t | 预留氦气流量设定值 |
| 9 | `ArFLOWRelay` | uint8_t | 氩气 MFC 继电器和氩气阀控制 |
| 10-11 | `ArOutValue` | uint16_t | 预留氩气流量设定值 |
| 12-15 | `footer` | uint32_t | 前 12 字节逐字节求和，小端 |

### 6.2 控制位映射

| 字段 | 位值 | 控制对象 |
|---|---:|---|
| `VolRelay` | `0x10` | `plasma_relay`，等离子电源继电器 |
| `VolRelay` | `0x01` | `vol_mod_relay`，调压器继电器 |
| `VolRelay` | `0x20` | `ctr_ass_fan`，5 V 控制辅助风扇 |
| `VolRelay` | `0x40` | `device_fan`，12 V 设备风扇 |
| `VolRelay` | `0x80` | `ctr_main_fan`，12 V 控制主风扇 |
| `HeFLOWRelay` | `0x10` | `He_MFC`，当前有效 MFC/流量控制器上电 |
| `HeFLOWRelay` | `0x01` | `he_valve`，氦气电磁阀 |
| `HeFLOWRelay` | `0x02` | `buzzer_1`，红色错误蜂鸣器，命令打开为长鸣 |
| `HeFLOWRelay` | `0x04` | `buzzer_2`，黄色提醒蜂鸣器，命令打开为长开；硬急停恢复时由固件自动响 2 次 |
| `ArFLOWRelay` | `0x10` | `Ar_MFC`，当前禁用，命令不会吸合 PC2 |
| `ArFLOWRelay` | `0x01` | `ar_valve`，氩气电磁阀 |
| `ArFLOWRelay` | `0x02` | `rgb_red`，RGB 红；当前会被系统状态指示逻辑周期覆盖 |
| `ArFLOWRelay` | `0x04` | `rgb_green`，RGB 绿；当前会被系统状态指示逻辑周期覆盖 |
| `ArFLOWRelay` | `0x08` | `rgb_yellow`，RGB 黄；当前会被系统状态指示逻辑周期覆盖 |
| `EmerStop` | 普通控制帧中非 0，且不等于 `0xA5` | 关闭当前已接入的全部输出：继电器、气阀、风扇、蜂鸣器、RGB；`cmd_uart` 专用握手帧例外 |

### 6.3 风扇调速字段

普通控制帧中，风扇仍然使用 `VolRelay` 中的控制位决定是否开启，开=100% 占空比，关=0%。

调速需要发送专用风扇调速帧：`EmerStop = 0xA5`。该帧只更新三路风扇 PWM，占空比范围为 `0-1000`，例如 `500` 表示 50%。专用风扇调速帧不会更新日志中的 `VolOutValue`、`HeOutValue`、`ArOutValue` 业务字段。

| 风扇别名 | 开关位 | 调速字段 | 说明 |
|---|---:|---|---|
| `ctr_ass_fan` | `VolRelay` 的 `0x20` | `VolOutValue` | PB5，5 V 控制辅助风扇 |
| `device_fan` | `VolRelay` 的 `0x40` | `HeOutValue` | PB6，12 V 设备风扇 |
| `ctr_main_fan` | `VolRelay` 的 `0x80` | `ArOutValue` | PB7，12 V 控制主风扇 |

兼容旧测试命令：普通控制帧里如果对应风扇开关位为 1，固件按 `1000/1000` 全速输出；如果开关位为 0，则输出 0。

## 7. USART1 状态日志

USART1 对应 CH340 调试串口，当前用于现场调试和操作者查看状态。它可以接收 16 字节控制命令，但回传内容保持为 ASCII 状态日志，不回传 16 字节二进制状态包。固件每约 `1000 ms` 输出一次状态日志。

USART6 对应 `485-2`，PC6/PC7，J365，是上位机交互命令口，代码别名为 `cmd_uart`。它可以接收同一套 16 字节控制命令；固件每约 `300 ms` 主动回传一帧 28 字节二进制状态包。

`cmd_uart` 支持上位机连接握手。上位机连接到 485-2 后，先发送握手请求帧：

```text
FF FE C5 A5 A5 5A 3C 3C C3 96 96 69 36 07 00 00
```

下位机收到并校验通过后，会立即通过 `cmd_uart` 回传 ACK：

```text
FF FE CA A5 A5 5A 3C 3C C3 96 96 69 3B 07 00 00
```

该握手帧只用于 `cmd_uart` 连接确认，不会进入普通控制逻辑，也不会改变继电器、气阀、MFC、风扇、蜂鸣器等执行器状态。握手成功后，`cmd_uart` 连接状态锁存为已连接；由于当前没有心跳机制，固件不会自动判定断开，除非板子复位。

注意：握手请求只能发到 USART6/`cmd_uart`。如果把这帧发到 USART1/`log_uart`，日志口会按普通控制帧处理，其中 `EmerStop=C5` 会触发命令急停。

三色灯当前作为系统状态指示灯使用，优先级如下：

| 优先级 | 状态 | 三色灯表现 |
|---:|---|---|
| 1 | 硬件急停触发 | 红灯快速闪烁 |
| 2 | `cmd_uart` 握手成功 | 绿灯常亮 |
| 3 | `cmd_uart` 未握手 | 黄灯慢速闪烁 |

日志串口 `log_uart` 不参与连接判断；无论日志串口是否连接，只要 `cmd_uart` 未完成握手，三色灯就是黄色慢闪。

板载 LED1/LED2/LED3 当前也作为 `cmd_uart` 和急停状态指示使用：

| 状态 | LED1/LED2/LED3 表现 |
|---|---|
| 硬件急停或命令急停 | 三颗 LED 同步闪烁 |
| `cmd_uart` 握手成功 | LED1 常亮，LED2/LED3 熄灭 |
| `cmd_uart` 未握手 | LED1 -> LED2 -> LED3 跑马灯 |

USART6 状态包字段与上位机命令格式一致：

| 字段 | 回传含义 |
|---|---|
| `EmerStop` | 当前急停状态 |
| `VolRelay` | 等离子电源、调压器继电器和三路风扇的实际开关位 |
| `VolOutValue` | 当前保存的电压/预留设定值 |
| `HeFLOWRelay` | He_MFC、氦气阀、蜂鸣器 1/2 的实际开关位 |
| `HeOutValue` | He_MFC 当前目标流量，单位 `0.01 L/min` |
| `ArFLOWRelay` | Ar_MFC、氩气阀、RGB R/G/Y 的实际开关位；RGB 当前主要反映系统状态灯 |
| `ArOutValue` | Ar_MFC 当前目标流量，单位 `0.01 L/min` |
| `footer` | 前 12 字节逐字节求和，小端 |

状态包前 16 字节与命令包格式一致，后 12 字节为扩展字段：

| 字节位置 | 字段 | 类型 | 回传含义 |
|---|---|---|---|
| 16-19 | `PlasmaFeedbackVpp` | float32，小端 | 等离子反馈 Vpp，单位 V，不做倍率放大 |
| 20-23 | `HePressureValue` | float32，小端 | 氦气压力值，单位 MPa |
| 24-27 | `ArPressureValue` | float32，小端 | 氩气压力值，单位 MPa |

| `OK/WAIT/FAULT` | He_MFC 跟踪正常/等待反馈/跟踪异常 |
| `DISABLED` | 通道按配置禁用，当前不会动作 |

急停命令触发时，当前代码会关闭：

```text
plasma_relay
vol_mod_relay
He_MFC / HE_MFC_PWR_EN
Ar_MFC / AR_MFC_PWR_EN
he_valve
ar_valve
ctr_ass_fan
device_fan
ctr_main_fan
buzzer_1
buzzer_2
rgb_red/rgb_green/rgb_yellow
LED1/LED2/LED3
```

命令急停会先关闭 RGB 和板载 LED，但主循环中的系统状态指示逻辑随后会接管显示：命令急停状态下 LED1/LED2/LED3 同步闪烁；三色灯在命令急停时不强制红灯，仍按 `cmd_uart` 连接状态显示黄灯慢闪或绿灯常亮。硬件急停触发时，三色灯红灯快速闪烁。

常闭硬件急停输入 `emergency_stop_switch` 触发时，代码执行独立的硬急停策略：

```text
buzzer_1 单次 1.5s，重复 5 次
rgb_red 快速闪烁，rgb_green/rgb_yellow 关闭
he_valve 关闭
ar_valve 关闭
He_MFC 目标流量设为 0.00 L/min
Ar_MFC 目标流量设为 0.00 L/min
vol_mod_relay 关闭
plasma_relay 关闭
buzzer_2 关闭
```

硬急停期间，ADC 采样、压力传感器通讯、USART1 日志和 USART6 上位机通讯都继续运行；USART6 仍按约 300 ms 周期回传状态包。硬急停按下期间收到的控制命令不会落到执行器，避免重新打开气阀、继电器或打断蜂鸣器提示。

硬急停恢复后：

```text
rgb_red 关闭
rgb_yellow 关闭
rgb_green 打开
buzzer_1 停止
buzzer_2 单次 1.5s，重复 2 次
急停状态位恢复为 0
```

恢复后不会自动重新打开氦气/氩气电磁阀，也不会恢复 MFC 流量设定；流量目标保持 0.00 L/min，需要操作者重新发送命令设置。

## 11. 联调注意事项

1. 继电器和气阀当前都按“高电平开启、低电平关闭”实现，并已由前期测试确认继电器命令对应正确。
2. `he_valve`、`ar_valve` 输出开启后外部会通 24V，实际接电磁阀前应先空载或用万用表确认。
3. `initial_limit_switch`、`max_limit_switch` 当前按低电平表示被压到；若后续硬件版本相反，应修改 `bsp_limit_switch.c` 中的 `LIMIT_PRESSED_LEVEL`。
4. USART1 用于调试日志，也可以 HEX 发送命令；USART6/485-2 用于上位机交互，会每约 300 ms 主动发送 28 字节二进制状态包。
5. 三色灯和 LED1/LED2/LED3 当前由系统状态逻辑接管，普通 RGB 命令只适合验证协议位和状态包字段，不适合作为长期灯色控制。
6. 后续接入 DAC/ADC/RS485 时，应继续使用业务别名封装，不建议在协议层直接写 GPIO 或外设寄存器。

## 12. 各模块串口测试命令

串口参数：

```text

115200 baud
8 data bits
1 stop bit
no parity
HEX 发送
```

通过 USART1 发送命令后，固件会继续周期性输出 ASCII 状态日志。通过 USART6 发送命令后，固件会执行命令，并每约 300 ms 回传一帧 28 字节 HEX 状态包；前 16 字节字段和命令包一致，后续字段为 float32 格式的等离子反馈 Vpp、氦气压力和氩气压力。

### 12.8 限位开关测试

限位开关不需要发送专用命令。固件会在周期状态日志中输出：

```text
InitialLimit:0, MaxLimit:0
```

测试方法：

1. 保持串口接收日志打开；
2. 手动压下初始位置限位开关，观察 `InitialLimit` 是否变为 `1`；
3. 手动压下最大位置限位开关，观察 `MaxLimit` 是否变为 `1`；
4. 松开限位开关后，对应字段应恢复为 `0`。

当前代码按低电平触发处理，`bsp_limit_switch.c` 中配置为：

```c
#define LIMIT_PRESSED_LEVEL GPIO_PIN_RESET
```

如果后续硬件版本改为高电平触发，再改为：

```c
#define LIMIT_PRESSED_LEVEL GPIO_PIN_SET
```
