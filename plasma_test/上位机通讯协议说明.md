# 等离子控制板上位机通讯协议说明

> 本文档面向上位机软件开发，用于实现上位机与 `plasma_test` 下位机固件的通讯。  
> 当前协议以 USART6 / 485-2 / `cmd_uart` 作为正式上位机通讯口；USART1 / `log_uart` 主要用于调试日志。

## 1. 通讯接口

| 项目 | 参数 |
|---|---|
| 正式上位机通讯口 | USART6 / `cmd_uart` |
| 板端接口 | 485-2 / J365 / `485_A_2`、`485_B_2` |
| MCU 引脚 | PC6 = USART6_TX，PC7 = USART6_RX |
| 波特率 | 115200 |
| 数据位 | 8 |
| 校验位 | None |
| 停止位 | 1 |
| 流控 | None |
| 字节序 | 小端 |

USART1 / `log_uart` 也能接收同样的 16 字节控制帧，但它的主要用途是输出 ASCII 状态日志，不建议上位机正式控制使用。

## 2. 通讯流程

推荐上位机启动流程：

1. 打开 USART6 对应串口，配置为 `115200, 8N1`。
2. 发送 `cmd_uart` 握手请求帧。
3. 等待下位机返回 ACK。
4. ACK 正确后，认为板子已连接。
5. 接收下位机每约 `300 ms` 主动上传的 28 字节状态包。
6. 需要控制设备时，发送 16 字节控制命令。
7. 发送命令后，以上传状态包中的实际状态为准，不要只以上位机本地命令缓存为准。

当前没有心跳断线机制。握手成功后，下位机内部会锁存 `cmd_uart` 已连接状态，直到板子复位。

## 3. 握手协议

握手只能通过 USART6 / `cmd_uart` 发送。

上位机发送握手请求：

```text
FF FE C5 A5 A5 5A 3C 3C C3 96 96 69 36 07 00 00
```

下位机返回 ACK：

```text
FF FE CA A5 A5 5A 3C 3C C3 96 96 69 3B 07 00 00
```

握手帧仍然使用 16 字节基础帧格式和校验规则，但下位机在 `cmd_uart` 上识别到该组合后不会进入普通控制逻辑，所以不会动作继电器、气阀、MFC、风扇、蜂鸣器等执行器。

注意：不要把握手请求发到 USART1 / `log_uart`。USART1 会按普通控制帧处理，其中 `EmerStop=C5` 会触发命令急停。

## 4. 基础帧格式

上位机发送的普通控制命令固定为 16 字节。

| 字节位置 | 字段 | 类型 | 字节序 | 说明 |
|---|---|---|---|---|
| 0-1 | `header` | uint16 | 小端 | 固定 `0xFEFF`，发送字节为 `FF FE` |
| 2 | `EmerStop` | uint8 | - | 急停/特殊命令字段 |
| 3 | `VolRelay` | uint8 | - | 电源继电器、调压器继电器、风扇开关位 |
| 4-5 | `VolOutValue` | uint16 | 小端 | 电压/调压器预留设定值；风扇调速帧中为 5V 风扇占空比 |
| 6 | `HeFLOWRelay` | uint8 | - | He_MFC、氦气阀、蜂鸣器位 |
| 7-8 | `HeOutValue` | uint16 | 小端 | He_MFC 目标流量，单位 `0.01 L/min`；风扇调速帧中为 `device_fan` 占空比 |
| 9 | `ArFLOWRelay` | uint8 | - | Ar_MFC、氩气阀、RGB 位 |
| 10-11 | `ArOutValue` | uint16 | 小端 | Ar_MFC 目标流量，单位 `0.01 L/min`；风扇调速帧中为 `ctr_main_fan` 占空比 |
| 12-15 | `footer` | uint32 | 小端 | 前 12 字节逐字节求和 |

## 5. 校验规则

校验值是前 12 个字节的无符号累加和，按 uint32 小端放入字节 12-15。

伪代码：

```c
uint32_t checksum = 0;
for (int i = 0; i < 12; i++) {
    checksum += packet[i];
}
packet[12] = checksum & 0xFF;
packet[13] = (checksum >> 8) & 0xFF;
packet[14] = (checksum >> 16) & 0xFF;
packet[15] = (checksum >> 24) & 0xFF;
```

示例：打开等离子电源继电器。

前 12 字节：

```text
FF FE 00 10 00 00 00 00 00 00 00 00
```

求和为 `0x0000020D`，小端为 `0D 02 00 00`，完整帧：

```text
FF FE 00 10 00 00 00 00 00 00 00 00 0D 02 00 00
```

## 6. 普通控制字段

当 `EmerStop = 0x00` 时，按普通控制帧执行。

### 6.1 `VolRelay`

| 位值 | 名称 | 控制对象 | 说明 |
|---:|---|---|---|
| `0x01` | `RELAY_VOL_MOD_ON` | `vol_mod_relay` | 调压器继电器，PC1 |
| `0x10` | `RELAY_PLASMA_ON` | `plasma_relay` | 等离子电源继电器，PA7 |
| `0x20` | `CTR_ASS_FAN_ON` | `ctr_ass_fan` | 5V 控制辅助风扇，PB5 |
| `0x40` | `DEVICE_FAN_ON` | `device_fan` | 12V 设备风扇，PB6 |
| `0x80` | `CTR_MAIN_FAN_ON` | `ctr_main_fan` | 12V 控制主风扇，PB7 |

普通控制帧中，风扇开关位为 1 时按 100% 占空比输出；为 0 时关闭。需要调速时使用专用风扇调速帧。

### 6.2 `HeFLOWRelay`

| 位值 | 名称 | 控制对象 | 说明 |
|---:|---|---|---|
| `0x01` | `RELAY_GAS_VALVE_ON` | `he_valve` | 氦气电磁阀，PD12，高电平开 |
| `0x02` | `BUZZER_1_ON` | `buzzer_1` | 红色错误蜂鸣器，命令打开为长鸣 |
| `0x04` | `BUZZER_2_ON` | `buzzer_2` | 黄色提醒蜂鸣器，命令打开为长开 |
| `0x10` | `RELAY_FLOW_METER_ON` | `He_MFC` | He_MFC 上电，PC3/SWRAY2 |

`HeOutValue` 是 He_MFC 目标流量，单位为 `0.01 L/min`。

```text
100  -> 1.00 L/min
500  -> 5.00 L/min
1000 -> 10.00 L/min
```

当前 He_MFC 有效，满量程按 30 L/min 配置。

### 6.3 `ArFLOWRelay`

| 位值 | 名称 | 控制对象 | 说明 |
|---:|---|---|---|
| `0x01` | `RELAY_GAS_VALVE_ON` | `ar_valve` | 氩气电磁阀，PD13，高电平开 |
| `0x02` | `RGB_RED_ON` | `rgb_red` | 三色灯红色位，当前会被系统状态灯逻辑覆盖 |
| `0x04` | `RGB_GREEN_ON` | `rgb_green` | 三色灯绿色位，当前会被系统状态灯逻辑覆盖 |
| `0x08` | `RGB_YELLOW_ON` | `rgb_yellow` | 三色灯黄色位，当前会被系统状态灯逻辑覆盖 |
| `0x10` | `RELAY_FLOW_METER_ON` | `Ar_MFC` | Ar_MFC 上电，PC2/SWRAY1 |

`ArOutValue` 是 Ar_MFC 目标流量，单位为 `0.01 L/min`。

当前 Ar_MFC 因硬件接线问题暂时禁用，发送上电和流量设定命令不会吸合 PC2；`ar_valve` 可正常单独控制。

## 7. 特殊命令

### 7.1 命令急停

普通控制帧中，如果 `EmerStop != 0x00` 且 `EmerStop != 0xA5`，下位机会执行命令急停关闭策略。

命令急停会关闭当前已接入的主要输出：

```text
plasma_relay
vol_mod_relay
He_MFC / Ar_MFC 电源
he_valve / ar_valve
ctr_ass_fan / device_fan / ctr_main_fan
buzzer_1 / buzzer_2
rgb_red / rgb_green / rgb_yellow
LED1 / LED2 / LED3
```

示例命令急停帧：

```text
FF FE F8 00 00 00 00 00 00 00 00 00 F5 02 00 00
```

注意：命令急停不同于硬件急停。硬件急停来自 INT3 常闭急停输入，策略见第 10 节。

### 7.2 风扇调速帧

当 `EmerStop = 0xA5` 时，该帧为风扇调速专用帧，只更新三路风扇 PWM。

| 字段 | 含义 |
|---|---|
| `VolRelay` | 三路风扇开关位，仍使用 `0x20/0x40/0x80` |
| `VolOutValue` | `ctr_ass_fan` 占空比，范围 `0-1000` |
| `HeOutValue` | `device_fan` 占空比，范围 `0-1000` |
| `ArOutValue` | `ctr_main_fan` 占空比，范围 `0-1000` |

占空比规则：

```text
0    -> 关闭
500  -> 50%
1000 -> 100%
>1000 会被限制为 1000
如果开关位为 0，则对应风扇占空比强制为 0
如果开关位为 1 且占空比字段为 0，则按 100% 兼容处理
```

示例：三路风扇分别设置为 30%、60%、90%。

```text
FF FE A5 E0 2C 01 00 58 02 00 84 03 90 04 00 00
```

## 8. 下位机状态包

`cmd_uart` 会每约 `300 ms` 主动上传一帧 28 字节状态包。上位机应持续接收并解析该状态包，用它更新界面中的实际状态。

状态包前 16 字节与基础帧格式一致，后 12 字节为扩展字段。

| 字节位置 | 字段 | 类型 | 字节序 | 单位/含义 |
|---|---|---|---|---|
| 0-1 | `header` | uint16 | 小端 | 固定 `0xFEFF` |
| 2 | `EmerStop` | uint8 | - | 当前急停状态，非 0 表示急停/关断状态 |
| 3 | `VolRelay` | uint8 | - | 继电器和风扇实际开关位 |
| 4-5 | `VolOutValue` | uint16 | 小端 | 当前保存的电压/预留设定值 |
| 6 | `HeFLOWRelay` | uint8 | - | He_MFC、氦气阀、蜂鸣器实际状态位 |
| 7-8 | `HeOutValue` | uint16 | 小端 | He_MFC 当前目标流量，单位 `0.01 L/min` |
| 9 | `ArFLOWRelay` | uint8 | - | Ar_MFC、氩气阀、RGB 状态位 |
| 10-11 | `ArOutValue` | uint16 | 小端 | Ar_MFC 当前目标流量，单位 `0.01 L/min` |
| 12-15 | `footer` | uint32 | 小端 | 前 12 字节逐字节求和 |
| 16-19 | `PlasmaFeedbackVpp` | float32 | 小端 | 等离子反馈 Vpp，单位 V |
| 20-23 | `HePressureValue` | float32 | 小端 | 氦气压力，单位 MPa；无效时为 `0.0` |
| 24-27 | `ArPressureValue` | float32 | 小端 | 氩气压力，单位 MPa；无效时为 `0.0` |

状态包校验只覆盖前 12 字节，和控制帧一致；扩展字段目前不参与校验。

## 9. 状态位解析

状态包中的 `VolRelay`、`HeFLOWRelay`、`ArFLOWRelay` 使用与普通控制命令相同的位定义，但代表下位机当前实际状态。

上位机界面建议：

- 继电器、气阀、风扇、蜂鸣器、RGB 的开关显示，应以状态包位为准；
- MFC 目标流量显示，应以状态包 `HeOutValue/ArOutValue` 为准；
- 等离子反馈 Vpp、压力值，应解析扩展 float32 字段；
- 命令发出后不要立即假定执行成功，应等待下一帧或几帧状态包确认。

RGB 位当前主要反映系统状态灯：

```text
硬件急停：红灯快速闪烁
cmd_uart 已握手：绿灯常亮
cmd_uart 未握手：黄灯慢速闪烁
```

所以 RGB 命令位只建议用于协议测试，不建议上位机把它作为自由颜色控制。

板载 LED1/LED2/LED3 也用于连接和急停状态指示：

```text
硬件急停或命令急停：LED1/LED2/LED3 同步闪烁
cmd_uart 已握手：LED1 常亮，LED2/LED3 熄灭
cmd_uart 未握手：LED1 -> LED2 -> LED3 跑马灯
```

## 10. 硬件急停行为

硬件急停输入为 INT3 / PE13，接常闭急停。正常闭合时为低电平；急停按下开路后变为高电平并触发硬件急停策略。

硬件急停触发后：

- `buzzer_1` 红色错误蜂鸣器响 5 个单次；
- 三色灯红灯快速闪烁；
- LED1/LED2/LED3 同步闪烁；
- `he_valve`、`ar_valve` 关闭；
- He_MFC、Ar_MFC 目标流量设为 `0.00 L/min`；
- `vol_mod_relay`、`plasma_relay` 关闭；
- `buzzer_2` 关闭；
- ADC 采样继续运行；
- 压力传感器通讯继续运行；
- USART1 日志继续输出；
- USART6 状态包继续上传。

硬件急停恢复后：

- 红色蜂鸣器停止；
- 黄色蜂鸣器响 2 个单次；
- 三色灯回到绿色常亮或黄色慢闪，由 `cmd_uart` 是否已握手决定；
- LED1/LED2/LED3 回到 `cmd_uart` 连接状态指示；
- 被关闭的电磁阀、继电器不会自动重新打开；
- MFC 目标流量保持 `0.00 L/min`，需要操作者重新设置。

硬件急停按下期间，下位机仍接收串口数据，但控制命令不会落到执行器。

## 11. 上位机解析建议

### 11.1 接收状态包

串口接收建议使用滑动缓冲区：

1. 不断读入串口字节；
2. 查找包头字节序列 `FF FE`；
3. 如果缓冲区不足 16 字节，继续等待；
4. 对前 16 字节按基础帧校验；
5. 如果需要解析完整状态包，继续等待到 28 字节；
6. 前 16 字节校验正确后，解析 16-27 字节扩展字段；
7. 如果校验失败，丢弃当前包头第一个字节，继续查找下一个包头。

### 11.2 发送控制命令

上位机每次发送命令时建议完整构造 16 字节包：

1. 写入固定包头 `FF FE`；
2. 写入控制字段；
3. 对前 12 字节求和；
4. 写入 4 字节小端校验；
5. 发送；
6. 等待状态包确认。

不要只发送变化字段；下位机每次收到普通控制帧会按当前帧的字段整体刷新相关执行器。

### 11.3 发送频率

当前下位机没有对上位机命令做队列。建议：

- 普通控制命令不要高频连续发送；
- 人机界面按钮类命令，按操作发送即可；
- 滑块类命令建议限速，例如 `100-200 ms` 发送一次；
- 风扇调速和 MFC 流量设定发送后，以状态包回读值确认。

## 13. Python 解析示例

```python
import struct

HEADER = b"\xFF\xFE"

def checksum12(data: bytes) -> int:
    return sum(data[:12]) & 0xFFFFFFFF

def build_packet(emer, vol_relay, vol_value, he_relay, he_value, ar_relay, ar_value):
    pkt = bytearray(16)
    pkt[0:2] = HEADER
    pkt[2] = emer & 0xFF
    pkt[3] = vol_relay & 0xFF
    pkt[4:6] = struct.pack("<H", vol_value & 0xFFFF)
    pkt[6] = he_relay & 0xFF
    pkt[7:9] = struct.pack("<H", he_value & 0xFFFF)
    pkt[9] = ar_relay & 0xFF
    pkt[10:12] = struct.pack("<H", ar_value & 0xFFFF)
    pkt[12:16] = struct.pack("<I", checksum12(pkt))
    return bytes(pkt)

def parse_state_packet(pkt: bytes):
    if len(pkt) < 28:
        raise ValueError("state packet needs 28 bytes")
    if pkt[0:2] != HEADER:
        raise ValueError("bad header")
    recv_sum = struct.unpack_from("<I", pkt, 12)[0]
    calc_sum = checksum12(pkt)
    if recv_sum != calc_sum:
        raise ValueError(f"bad checksum recv={recv_sum:#x} calc={calc_sum:#x}")

    state = {
        "emer_stop": pkt[2],
        "vol_relay": pkt[3],
        "vol_out_value": struct.unpack_from("<H", pkt, 4)[0],
        "he_flow_relay": pkt[6],
        "he_target_lpm": struct.unpack_from("<H", pkt, 7)[0] / 100.0,
        "ar_flow_relay": pkt[9],
        "ar_target_lpm": struct.unpack_from("<H", pkt, 10)[0] / 100.0,
        "plasma_vpp_v": struct.unpack_from("<f", pkt, 16)[0],
        "he_pressure_mpa": struct.unpack_from("<f", pkt, 20)[0],
        "ar_pressure_mpa": struct.unpack_from("<f", pkt, 24)[0],
    }
    return state

# He_MFC 1.00 L/min + he_valve ON
cmd = build_packet(
    emer=0x00,
    vol_relay=0x00,
    vol_value=0,
    he_relay=0x11,
    he_value=100,
    ar_relay=0x00,
    ar_value=0,
)
print(cmd.hex(" ").upper())
```
