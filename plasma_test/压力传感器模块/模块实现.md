# 双路 RS485 Modbus-RTU 气瓶压力传感器模块实现说明

本文档记录 `plasma_test` 中压力传感器模块的当前实现方式、板端资源分配、配置入口和后续补充步骤。

## 1. 功能目标

本模块用于读取等离子设备两路气源的气瓶压力：

| 气体 | 业务含义 | 板端接口 | MCU 串口 |
|---|---|---|---|
| 氦气 | 氦气瓶压力检测 | J367 / `485_A_3`、`485_B_3` | USART2，PA2/PA3 |
| 氩气 | 氩气瓶压力检测 | J366 / `485_A_1`、`485_B_1` | UART4，PA0/PA1 |

说明：原草稿中 UART4 曾写为 PC10/PC11；当前固件按 `板子资源.md` 和实际板卡资源实现为 PA0/PA1。

模块目标：

- 通过 Modbus-RTU 读取压力寄存器；
- 计算压力值和气瓶剩余百分比；
- 维护在线、有效、超时、CRC 错误等通信状态；
- 后续为气路控制、报警和上位机显示提供数据。

## 3. RS485 硬件说明

板卡 RS485 收发器为自动方向控制，软件不需要单独控制 DE/RE GPIO。

软件只需要使用对应 UART 的 TX/RX：

| 接口 | 串口 | TX | RX | 说明 |
|---|---|---|---|---|
| 485-3 / J367 | USART2 | PA2 | PA3 | 氦气压力 |
| 485-1 / J366 | UART4 | PA0 | PA1 | 氩气压力 |

J366 和 J367 使用相同的四针定义：

| 引脚 | 网络 | 连接对象 |
|---:|---|---|
| 1 | `VCC_IN` | 传感器电源正极 |
| 2 | `485_B_x` | 传感器 RS485 B |
| 3 | `485_A_x` | 传感器 RS485 A |
| 4 | GND | 传感器电源负极/通信参考地 |

`VCC_IN` 是控制板经过保护的主输入电源，当前板卡按 12 V 输入设计。接线前必须核对传感器铭牌供电范围；断电后接线，不要仅凭线色判断电源和 A/B。如果通信始终离线，在供电和地址确认正确后，可断电交换 A/B 再测试。

依据 `MODBUS压力、液位变送器通信协议24年12月1.doc`，两个串口均使用 `9600, 8N1`。

## 4. Modbus RTU 层

当前支持：

- 功能码 `0x03`：Read Holding Registers；
- 标准 Modbus CRC16；
- 非阻塞接收，UART 中断只收字节并置位状态；
- 主循环调用 `Modbus_Process()` 完成解析和超时判断；
- 超时、CRC 错误、异常响应、UART 错误统计。

CRC 参数：

| 项目 | 值 |
|---|---|
| 初值 | `0xFFFF` |
| 多项式 | `0xA001` |
| 发送顺序 | CRC 低字节在前，高字节在后 |

读保持寄存器请求格式：

```text
Slave Function Addr_H Addr_L Count_H Count_L CRC_L CRC_H
```

示例：

```text
01 03 00 02 00 05 24 09
```

含义：读取从站 `1` 的 `0x0002`-`0x0006`，共 5 个寄存器。

## 5. 气压业务层配置

配置结构位于 `gas_pressure.h`：

```c
typedef struct
{
  bool enabled;
  UART_HandleTypeDef *uart;
  uint8_t slave_id;
  uint16_t pressure_register;
  uint16_t register_count;
  float scale;
  float offset;
} GasPressure_Config_t;
```

字段说明：

| 字段 | 说明 |
|---|---|
| `enabled` | 是否启用该通道，两路默认启用 |
| `uart` | 对应串口，氦气为 `&he_pressure_uart`，氩气为 `&ar_pressure_uart` |
| `slave_id` | Modbus 从站地址，两条独立 RS485 总线均默认为 `1` |
| `pressure_register` | 连续读取起始地址，固定为 `0x0002` |
| `register_count` | 连续读取 `0x0002`-`0x0006`，固定为 5 个寄存器 |
| `scale` | 换算为 MPa 后的二次标定比例，默认 `1.0` |
| `offset` | 换算为 MPa 后的二次标定偏移，默认 `0.0` |

当前 `gas_pressure.c` 中两路默认配置为：

```c
.enabled = true
.slave_id = 1
.pressure_register = 0x0002
.register_count = 5
.scale = 1.0f
.offset = 0.0f
```

每路传感器分别位于独立 RS485 总线，因此两路同时使用从站地址 `1` 不会冲突。

### 5.1 寄存器解析

| 地址 | 含义 | 解析 |
|---|---|---|
| `0x0002` | 单位 | 按协议单位编码换算为 MPa |
| `0x0003` | 小数位 | `0`-`4`，原始数值除以 `10^n` |
| `0x0004` | PV | int16 补码，当前压力 |
| `0x0005` | 量程零点 | int16 补码 |
| `0x0006` | 量程满点 | int16 补码 |

支持的压力单位编码为 `0`-`15`（MPa、kPa、Pa、bar、mbar、kgf/cm2、PSI、mH2O、mmH2O、inH2O、cmH2O、mHg、mmHg、inHg、atm、Torr）。温度、长度等非压力单位会被标记为无效数据。

## 6. 轮询流程

主循环调用：

```c
GasPressure_Process();
```

轮询节拍：

| 项目 | 当前值 |
|---|---:|
| 单通道轮询周期 | `500 ms` |
| 氦气/氩气错峰 | `250 ms` |
| 单次请求超时 | `300 ms` |
| 离线判断 | `5000 ms` 无有效数据 |

流程：

1. 检查通道是否已配置；
2. 到达轮询时间后发送 Modbus 读保持寄存器请求；
3. UART 中断接收响应字节；
4. `Modbus_Process()` 校验 CRC 并解析寄存器；
5. `gas_pressure.c` 将 raw 值换算为压力和剩余百分比；
6. 日志中显示在线/有效/压力值。

## 7. USART1 日志

USART1 状态日志新增：

```text
===Gas Pressure===
  He Pressure: CONFIGURED  Online: OFF  Valid: FAULT  Value=0.00  Remain=0.0%
  Ar Pressure: CONFIGURED  Online: OFF  Valid: FAULT  Value=0.00  Remain=0.0%
```

配置完成并通信正常后，预期类似：

```text
===Gas Pressure===
  He Pressure: CONFIGURED  Online: ON  Valid: OK  Value=12.34  Remain=61.7%
  Ar Pressure: CONFIGURED  Online: ON  Valid: OK  Value=10.21  Remain=51.0%
```

压力会根据传感器的单位和小数位自动换算为 MPa。

`cmd_uart` 上传给上位机的状态包中也包含压力值：

| 字节位置 | 字段 | 类型 | 单位 | 说明 |
|---|---|---|---|---|
| 20-23 | `HePressureValue` | float32，小端 | MPa | 氦气压力值 |
| 24-27 | `ArPressureValue` | float32，小端 | MPa | 氩气压力值 |

如果当前压力数据无效，对应字段上传 `0.0f`。

## 8. 现场配置注意事项

- 出厂默认按从站地址 `1`、`9600/N/8/1` 通信；如果传感器曾被改参，需先用 USB-RS485 工具确认实际参数。
- 两路总线独立，不需要为氦气和氩气设置不同地址。
- TX/RX 调试日志开关已在 Modbus 上下文中预留，当前未输出到 USART1，避免日志过长影响主循环。

## 9. 验收建议

1. 先确认传感器供电和 A/B 接线；
2. 用 USB-RS485 工具单独读通传感器，确认 Slave ID、波特率和寄存器；
3. 确认两路传感器的地址都是 `1`，如有改动则同步修改 `gas_pressure.c`；
4. 烧录后观察 USART1 `Gas Pressure` 日志；
5. 故意断开传感器，确认 5 秒后 `Online: OFF`；
6. 故意填错 Slave ID，确认 timeout 计数增加。

## 10. Jetson 烧录

当前固件位于：

```text
plasma_test/MDK-ARM/plasma_test/plasma_test.hex
```

ST-Link 与控制板 J332 的连接为：

| J332 引脚 | 信号 | ST-Link |
|---:|---|---|
| 1 | GND | GND |
| 2 | SWCLK | SWCLK |
| 3 | SWDIO | SWDIO |
| 4 | `STM_3V3` | 目标电压参考 |

控制板应使用自身电源正常供电。J332 第 4 脚仅作目标电压参考；使用会从 3.3 V 脚向外供电的简化版 ST-Link 前，必须先确认不会与控制板自身 3.3 V 电源互相反灌。

只探测下载器和目标芯片，不写 Flash：

```bash
plasma_test/scripts/flash_stm32.sh
```

确认探测到 STM32F407 后执行烧录：

```bash
plasma_test/scripts/flash_stm32.sh --write
```

J332 没有 NRST。烧录完成后如果程序没有自动运行，手动按一下控制板 RESET。
