# 测试数据包集合
# 数据包格式说明：
# 总长度：16字节
# 字节0-1：包头 0xFEFF (小端序：FF FE)
# 字节2：紧急停止标志 (0x00=正常, 0xF8=紧急停止)
# 字节3：等离子电源继电器状态 (高4位=等离子电源, 低4位=调压器)
# 字节4-5：等离子电源输出值 (小端序)
# 字节6：氦气流量继电器状态 (高4位=流量计, 低4位=电磁阀)
# 字节7-8：氦气输出值 (小端序)
# 字节9：氩气流量继电器状态 (高4位=流量计, 低4位=电磁阀)
# 字节10-11：氩气输出值 (小端序)
# 字节12-15：校验和 (前12字节之和，小端序)

FF FE 00 01 32 00 10 2C 01 01 58 02 C8 02 00 00

# 使用说明：
# 1. 每行16个字节的十六进制数据代表一个完整的数据包
# 2. 可以通过串口调试工具发送这些数据包进行测试
# 3. 校验和计算：前12个字节的和（按字节相加）
# 4. 小端序：低字节在前，高字节在后
