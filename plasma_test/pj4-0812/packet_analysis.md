# STM32等离子控制系统数据包分析文档

## 数据包结构

### 总体格式
数据包总长度：**16字节**

| 字节位置 | 字段名称 | 数据类型 | 描述 |
|---------|---------|---------|------|
| 0-1 | header | uint16_t | 包头，固定值0xFEFF |
| 2 | EmerStop | uint8_t | 紧急停止标志 |
| 3 | VolRelay | uint8_t | 等离子电源继电器状态 |
| 4-5 | VolOutValue | uint16_t | 等离子电源输出值 |
| 6 | HeFLOWRelay | uint8_t | 氦气流量继电器状态 |
| 7-8 | HeOutValue | uint16_t | 氦气输出值 |
| 9 | ArFLOWRelay | uint8_t | 氩气流量继电器状态 |
| 10-11 | ArOutValue | uint16_t | 氩气输出值 |
| 12-15 | footer | uint32_t | 校验和（前12字节之和） |

### 字段详细说明

#### 1. 包头 (header)
- **值**: 0xFEFF
- **小端序发送**: FF FE
- **用途**: 数据包识别标志

#### 2. 紧急停止 (EmerStop)
- **0x00**: 正常状态
- **0xF8**: 紧急停止激活

#### 3. 等离子电源继电器 (VolRelay)
- **高4位**: 等离子电源继电器状态 (0x10=开启, 0x00=关闭)
- **低4位**: 调压器继电器状态 (0x01=开启, 0x00=关闭)
- **示例**: 0x11 = 等离子电源和调压器都开启

#### 4. 等离子电源输出值 (VolOutValue)
- **范围**: 0-65535
- **单位**: ADC值
- **小端序**: 低字节在前

#### 5. 氦气流量继电器 (HeFLOWRelay)
- **高4位**: 流量计开关 (0x10=开启, 0x00=关闭)
- **低4位**: 电磁阀开关 (0x01=开启, 0x00=关闭)

#### 6. 氦气输出值 (HeOutValue)
- **范围**: 0-65535
- **单位**: ADC值
- **小端序**: 低字节在前

#### 7. 氩气流量继电器 (ArFLOWRelay)
- **高4位**: 流量计开关 (0x10=开启, 0x00=关闭)
- **低4位**: 电磁阀开关 (0x01=开启, 0x00=关闭)

#### 8. 氩气输出值 (ArOutValue)
- **范围**: 0-65535
- **单位**: ADC值
- **小端序**: 低字节在前

#### 9. 校验和 (footer)
- **计算方法**: 前12个字节的算术和
- **数据类型**: uint32_t
- **小端序**: 低字节在前

## 校验和计算示例

```c
// 计算校验和的C代码示例
uint32_t calculateChecksum(uint8_t* data) {
    uint32_t checksum = 0;
    for (int i = 0; i < 12; i++) {
        checksum += data[i];
    }
    return checksum;
}
```

## 测试数据包详细解析

### 测试包1：正常工作状态
```
FF FE 00 11 E8 03 11 F4 01 11 2C 01 A9 07 00 00
```

**解析**:
- 包头: FF FE (0xFEFF)
- 紧急停止: 00 (正常)
- 等离子电源继电器: 11 (等离子电源+调压器都开启)
- 等离子电源输出: E8 03 (0x03E8 = 1000)
- 氦气继电器: 11 (流量计+电磁阀都开启)
- 氦气输出: F4 01 (0x01F4 = 500)
- 氩气继电器: 11 (流量计+电磁阀都开启)
- 氩气输出: 2C 01 (0x012C = 300)
- 校验和: A9 07 00 00 (0x000007A9 = 1961)

**校验和验证**:
0xFF + 0xFE + 0x00 + 0x11 + 0xE8 + 0x03 + 0x11 + 0xF4 + 0x01 + 0x11 + 0x2C + 0x01 = 0x7A9 = 1961 ?

### 测试包2：紧急停止状态
```
FF FE F8 00 00 00 00 00 00 00 00 00 F8 00 00 00
```

**解析**:
- 包头: FF FE (0xFEFF)
- 紧急停止: F8 (紧急停止激活)
- 所有继电器: 00 (全部关闭)
- 所有输出值: 00 00 (全部为0)
- 校验和: F8 00 00 00 (0x000000F8 = 248)

**校验和验证**:
0xFF + 0xFE + 0xF8 + 0x00 + 0x00 + 0x00 + 0x00 + 0x00 + 0x00 + 0x00 + 0x00 + 0x00 = 0xF8 = 248 ?

## 使用方法

### 1. 串口调试工具发送
1. 打开串口调试工具
2. 设置波特率（根据系统配置）
3. 选择十六进制发送模式
4. 复制测试数据包（去掉空格）
5. 发送数据包

### 2. 程序测试
```c
// 测试数据包数组
uint8_t test_packet1[] = {0xFF, 0xFE, 0x00, 0x11, 0xE8, 0x03, 0x11, 0xF4, 0x01, 0x11, 0x2C, 0x01, 0xA9, 0x07, 0x00, 0x00};

// 模拟接收数据包
for (int i = 0; i < 16; i++) {
    recv_buf[rxIndex++] = test_packet1[i];
}

// 处理数据包
DealPortData(true);
```

### 3. 验证方法
1. 检查串口输出的调试信息
2. 验证数据包是否被正确解析
3. 确认校验和验证功能
4. 观察设备状态变化

## 常见问题

### Q: 数据包未被识别
**A**: 检查包头是否为0xFEFF，注意小端序发送

### Q: 校验和验证失败
**A**: 重新计算前12字节的和，确保计算正确

### Q: 设备状态未改变
**A**: 检查继电器状态字节的位设置是否正确

### Q: 输出值异常
**A**: 确认16位值的小端序发送顺序

## 调试建议

1. **开启调试日志**: 调用`DealPortData(true)`开启详细日志
2. **逐字节检查**: 对比发送和接收的每个字节
3. **校验和计算**: 手动验证校验和计算是否正确
4. **分步测试**: 先测试简单的数据包，再测试复杂场景
5. **错误注入**: 使用错误校验和的数据包测试错误处理
