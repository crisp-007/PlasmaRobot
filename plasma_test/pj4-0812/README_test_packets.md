# STM32等离子控制系统测试数据包

## 概述

本项目为STM32等离子控制系统生成了完整的测试数据包集合，用于验证串口通信和数据包处理功能。

## 文件说明

### 1. test_packets.txt
包含10个预定义的测试数据包，涵盖各种工作场景：
- 正常工作状态
- 紧急停止状态
- 部分设备开启
- 高输出值测试
- 最小输出值测试
- 错误校验和测试
- 单独氦气测试
- 单独氩气测试
- 边界值测试
- 混合状态测试

### 2. packet_analysis.md
详细的数据包分析文档，包含：
- 数据包结构说明
- 字段详细定义
- 校验和计算方法
- 使用方法和调试建议

### 3. packet_generator.py
Python数据包生成器，功能包括：
- 生成自定义数据包
- 解析和验证数据包
- 自动计算校验和
- 格式化十六进制输出

### 4. generate_all_packets.py
批量生成所有测试数据包的脚本

## 数据包格式

```
字节位置 | 字段名称        | 数据类型  | 描述
---------|----------------|----------|------
0-1      | header         | uint16_t | 包头 0xFEFF
2        | EmerStop       | uint8_t  | 紧急停止标志
3        | VolRelay       | uint8_t  | 等离子电源继电器状态
4-5      | VolOutValue    | uint16_t | 等离子电源输出值
6        | HeFLOWRelay    | uint8_t  | 氦气流量继电器状态
7-8      | HeOutValue     | uint16_t | 氦气输出值
9        | ArFLOWRelay    | uint8_t  | 氩气流量继电器状态
10-11    | ArOutValue     | uint16_t | 氩气输出值
12-15    | footer         | uint32_t | 校验和
```

## 使用方法

### 1. 串口调试工具测试
1. 打开串口调试工具
2. 设置正确的波特率
3. 选择十六进制发送模式
4. 从test_packets.txt复制数据包（去掉空格）
5. 发送数据包并观察系统响应

### 2. Python脚本测试
```bash
# 运行数据包生成器
python packet_generator.py

# 生成所有测试包
python generate_all_packets.py
```

## 校验和计算

校验和是前12个字节的算术和：
```c
uint32_t checksum = 0;
for (int i = 0; i < 12; i++) {
    checksum += packet_data[i];
}
```

## 继电器状态编码

每个继电器状态字节使用位操作：
- **高4位**: 主设备状态（流量计/等离子电源）
- **低4位**: 辅助设备状态（电磁阀/调压器）

示例：
- 0x11 = 主设备和辅助设备都开启
- 0x10 = 仅主设备开启
- 0x01 = 仅辅助设备开启
- 0x00 = 全部关闭

## 调试提示

- 开启调试日志：调用`DealPortData(true)`
- 检查包头：确保为0xFEFF（小端序：FF FE）
- 验证校验和：手动计算前12字节的和
- 观察继电器状态：检查位操作是否正确
- 监控串口输出：查看解析结果和错误信息

## 常见问题

**Q: 数据包未被识别？**
A: 检查包头是否正确，确保小端序发送

**Q: 校验和验证失败？**
A: 重新计算前12字节的和，检查计算方法

**Q: 设备状态未改变？**
A: 检查继电器状态字节的位设置

**Q: 输出值异常？**
A: 确认16位值的小端序发送顺序
