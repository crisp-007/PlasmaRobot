# STM32F407 等离子电源反馈采样功能执行文档

## 1. 功能目标

在 STM32F407VGT6 HAL 裸机工程中，实现等离子电源反馈信号的连续采集与计算。

外部反馈信号规格：

- 波形：正弦波
- 频率：约 30 kHz
- 电压范围：-30 V ~ +30 V
- 反馈比例：暂按 1 V 反馈对应 1 kV 高压输出
- MCU 采样引脚：PA6 / ADC1_IN6
- 硬件调理后 ADC 输入：约 0 ~ 3.34 V
- 采集方式：定时器触发 ADC + DMA Circular
- 推荐采样率：600 kS/s
- 推荐缓冲区：400 个 uint16_t 样本

模块应输出：

- ADC 原始最小值、最大值
- ADC 引脚电压最小值、最大值
- 外部反馈最小值、最大值
- 峰峰值 Vpp
- 峰值 Vpeak
- 直流偏置
- 交流有效值 Vrms
- 实际频率
- 高压峰值、峰峰值和有效值
- 无信号、削顶、频率异常等状态

## 2. 硬件换算关系

信号链：

```text
-30 V ~ +30 V
    ↓ 170 kΩ / 10 kΩ 分压
约 -1.67 V ~ +1.67 V
    ↓ 加约 1.67 V 偏置
约 0 V ~ 3.34 V
    ↓
PA6 / ADC1_IN6
```

理论关系：

```text
Vadc = Vbias + Vin × divider_ratio
```

其中：

```text
Vbias ≈ 1.67 V
divider_ratio = 10k / (170k + 10k) = 1 / 18
```

反向换算：

```text
Vin = (Vadc - Vbias) / divider_ratio
Vin = (Vadc - 1.67) × 18
```

理论对应：

| 外部反馈 | ADC引脚 |
|---:|---:|
| -30 V | 约0 V |
| -15 V | 约0.835 V |
| 0 V | 约1.67 V |
| +15 V | 约2.505 V |
| +30 V | 约3.34 V |

注意：正满量程理论值略高于 3.3 V，必须实现 ADC 顶部削顶检测，并通过实物确认实际安全量程。

## 3. CubeMX 配置

### 3.1 ADC1

```text
PA6                         = ADC1_IN6
Resolution                  = 12 bits
Scan Conversion Mode        = Disable
Continuous Conversion Mode  = Disable
External Trigger Source     = TIM2 TRGO
External Trigger Edge       = Rising Edge
DMA Continuous Requests     = Enable
Data Alignment              = Right
Number of Conversion        = 1
Sampling Time               = 15 cycles，必要时测试28 cycles
```

建议 User Label：

```text
PLASMA_FB_ADC
```

### 3.2 DMA

```text
Mode                    = Circular
Peripheral Increment    = Disable
Memory Increment        = Enable
Peripheral Data Width   = Half Word
Memory Data Width       = Half Word
Priority                = High 或 Very High
```

开启 ADC1 对应 DMA 中断。

### 3.3 TIM2

当前 APB1 Timer Clock 为 84 MHz。

目标 600 kS/s：

```text
Prescaler = 0
Period    = 139
TRGO      = Update Event
```

采样率：

```text
84 MHz / (139 + 1) = 600 kHz
```

30 kHz 信号每周期约 20 个采样点。

若 600 kS/s 运行不稳定，可改为 300 kS/s：

```text
Prescaler = 0
Period    = 279
```

## 9. DMA 回调

在 HAL 回调中仅置位，不进行浮点运算：

```c
void HAL_ADC_ConvHalfCpltCallback(
    ADC_HandleTypeDef *hadc)
{
    if (hadc->Instance == ADC1)
    {
        PlasmaFeedback_OnDmaHalfComplete();
    }
}

void HAL_ADC_ConvCpltCallback(
    ADC_HandleTypeDef *hadc)
{
    if (hadc->Instance == ADC1)
    {
        PlasmaFeedback_OnDmaComplete();
    }
}
```

模块内部：

```c
void PlasmaFeedback_OnDmaHalfComplete(void)
{
    g_half_ready = true;
}

void PlasmaFeedback_OnDmaComplete(void)
{
    g_full_ready = true;
}
```

统计计算放在主循环调用的：

```c
PlasmaFeedback_Process();
```

## 10. ADC 换算函数

ADC码值转引脚电压：

```c
static float AdcRawToPinVoltage(uint16_t raw)
{
    return (float)raw
        / (float)g_plasma_fb_cfg.adc_full_scale_code
        * g_plasma_fb_cfg.adc_vref_v;
}
```

ADC引脚电压转外部反馈：

```c
static float PinVoltageToFeedback(float pin_v)
{
    float bias =
        g_plasma_fb_cfg.bias_voltage_v
        + g_plasma_fb_cfg.bias_cal_v;

    float feedback_v =
        (pin_v - bias)
        / g_plasma_fb_cfg.divider_ratio;

    feedback_v =
        feedback_v * g_plasma_fb_cfg.gain_cal
        + g_plasma_fb_cfg.offset_cal_v;

    return feedback_v;
}
```

不要在单点换算时直接限制到 ±30 V，否则会掩盖过量程。

## 11. 波形统计

每个处理窗口计算：

```text
raw_min
raw_max
Vmin
Vmax
Vpp
Vpeak
Voffset
Vrms
Frequency
```

直流偏置：

```text
Voffset = mean(samples)
```

交流有效值：

```text
Vrms = sqrt(mean((sample - Voffset)^2))
```

峰峰值与峰值：

```text
Vpp   = Vmax - Vmin
Vpeak = Vpp / 2
```

对正弦波可用：

```text
Vpeak_rms = Vrms × sqrt(2)
```

作为交叉检查。

## 12. 频率计算

使用上升过零法：

```text
Vac[n] = Vfeedback[n] - Voffset
```

过零条件：

```text
Vac[n-1] < 0
Vac[n] >= 0
```

记录连续上升过零位置，计算多个周期平均频率：

```text
frequency =
    sample_rate
    × period_count
    / total_period_samples
```

建议线性插值过零位置：

```c
float fraction =
    -previous_value
    / (current_value - previous_value);

float crossing =
    (float)(i - 1U) + fraction;
```

至少使用 5 个完整周期计算结果。

## 13. 高压换算

若厂家定义确认为：

```text
1 V反馈峰值 = 1 kV高压峰值
```

则：

```c
hv_peak_kv = feedback_peak_v
    * feedback_to_hv_kv_per_v;

hv_vpp_kv = feedback_vpp_v
    * feedback_to_hv_kv_per_v;

hv_rms_kv = feedback_rms_v
    * feedback_to_hv_kv_per_v;
```

必须分别保存 peak、Vpp 和 RMS，不得统一命名为模糊的 `high_voltage`。

## 14. 诊断

### 14.1 削顶

任一样本满足：

```text
raw <= adc_clip_low_code
raw >= adc_clip_high_code
```

则：

```text
clipped = true
返回 PLASMA_FB_CLIPPED
```

保留本次统计结果供诊断。

### 14.2 无信号

当：

```text
feedback_vpp_v < min_valid_amplitude_v
```

则：

```text
signal_valid = false
返回 PLASMA_FB_NO_SIGNAL
```

### 14.3 频率异常

```text
abs(measured_frequency - nominal_frequency)
> frequency_tolerance_hz
```

则：

```text
frequency_valid = false
返回 PLASMA_FB_FREQUENCY_ABNORMAL
```

初始有效范围约为：

```text
27 kHz ~ 33 kHz
```

## 15. 初始化与运行流程

初始化：

```c
PlasmaFeedback_Init();
```

应完成：

1. 校验配置；
2. 清空缓冲区；
3. 清空测量结构；
4. 清除 DMA 标志；
5. 标记为未运行；
6. 不自动启动。

启动：

```c
PlasmaFeedback_Start();
```

应完成：

1. 检查未运行；
2. 清空旧数据；
3. 启动 ADC DMA；
4. 启动 TIM2；
5. 标记运行。

主循环：

```c
while (1)
{
    plasma_feedback_result_t result =
        PlasmaFeedback_Process();

    if ((result == PLASMA_FB_OK) ||
        (result == PLASMA_FB_CLIPPED) ||
        (result == PLASMA_FB_FREQUENCY_ABNORMAL))
    {
        plasma_feedback_measurement_t measurement;

        if (PlasmaFeedback_GetMeasurement(&measurement))
        {
            /* 上报或参与控制 */
        }
    }
}
```

停止：

```c
PlasmaFeedback_Stop();
```

应先停止 TIM2，再停止 ADC DMA。

## 16. 标定

### 16.1 零点偏置

输入 0 V，采集平均 ADC 引脚电压：

```text
bias_actual = adc_average / 4095 × VDDA
bias_cal_v  = bias_actual - bias_voltage_v
```

### 16.2 增益

输入已知电压：

```text
-20 V、0 V、+20 V
```

拟合：

```text
actual =
    calculated × gain_cal
    + offset_cal_v
```

### 16.3 VDDA

不应长期假定 VDDA 精确为 3.300 V。

可采用：

- 万用表实测；
- VREFINT 估算；
- 出厂标定后保存。

## 17. 测试用例

### 零输入

预期：

```text
ADC平均约1.67 V
反馈偏置接近0 V
Vpp接近0
返回NO_SIGNAL
```

### ±10 V，30 kHz

预期：

```text
min约-10 V
max约+10 V
Vpp约20 V
peak约10 V
RMS约7.07 V
频率约30 kHz
```

### ±20 V，30 kHz

预期：

```text
Vpp约40 V
peak约20 V
RMS约14.14 V
```

### 接近±30 V

检查：

- ADC 是否到 0 或 4095；
- 是否发生削顶；
- 运放是否失真；
- 实际可用满量程。

### 频率异常

输入 20 kHz 或 40 kHz，应报告频率异常。

### 断线

记录断线时 ADC 静态值、噪声和无信号判断效果。

## 18. 编程助手实现要求

1. 创建 `bsp_plasma_feedback.h/.c`。
2. 使用 PA6 / ADC1_IN6。
3. 使用 TIM2 TRGO 触发 ADC。
4. 使用 DMA Circular。
5. 默认 600 kS/s。
6. 默认 400 点缓冲区。
7. DMA 回调只置位。
8. 主循环调用 `PlasmaFeedback_Process()`。
9. 计算 min、max、Vpp、peak、offset、RMS、frequency。
10. 使用上升过零法测频，建议线性插值。
11. 实现无信号、削顶和频率异常检测。
12. 所有硬件比例、阈值、参考电压配置化。
13. 支持 bias、gain、offset 标定。
14. 禁止动态内存。
15. 所有 HAL 返回值必须检查。
16. 业务层通过结果快照读取数据。
17. 保留 peak、Vpp、RMS 三种高压结果。
18. 若 ADC1 或 TIM2 已被占用，必须显式处理资源冲突。
19. 注释使用中文，接口和类型使用英文。
20. 代码应能在 STM32F407VGT6 HAL 裸机工程中直接编译。

## 19. 验收标准

- 能持续采集约 30 kHz 正弦波；
- 采样时序由定时器保证；
- DMA 可持续循环；
- 标定后幅值误差满足项目要求；
- 频率结果稳定；
- 削顶时能报告；
- 无输入时能报告无信号；
- 业务层能读取完整结果快照；
- 停止后 TIM2 和 ADC DMA 正确关闭；
- 再次启动后仍能正常工作。
