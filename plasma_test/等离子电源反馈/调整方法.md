# 等离子反馈采样参数调节说明

## 1. 三个主要校准参数

### `bias_voltage_v`

```c
.bias_voltage_v = 1.715f;
```

表示外部反馈为 `0 V` 时，ADC 引脚对应的中心电压。

调节方法：

1. 将等离子输出设为 0。
2. 采集 ADC 平均值。
3. 按下式计算：

```text
bias_voltage_v = ADC平均值 / 4095 × adc_vref_v
```

4. 调整后，日志中的 `Offset` 应尽量接近 `0 V`。

它主要修正零点，一般不会明显改变 `Vpp`。

---

### `gain_cal`

```c
.gain_cal = 1.15f;
```

表示对理论换算结果进行比例修正：

```text
最终值 = 理论值 × gain_cal
```

调节方法：

```text
gain_cal = 示波器实际幅值 / 程序未校准幅值
```

程序偏小就增大，程序偏大就减小。应使用中等或较大的稳定输出进行校准，并在低、中、高三个幅值点验证。

它会影响 `Vpp`、`Peak`、`RMS` 和最终高压值。

---

### `offset_cal_v`

```c
.offset_cal_v = 0.0f;
```

表示完成增益修正后，再对最终结果固定加减一个电压：

```text
最终值 = 理论值 × gain_cal + offset_cal_v
```

例如程序在所有幅值下都固定大 `0.1 V`：

```c
.offset_cal_v = -0.1f;
```

如果误差随幅值成比例变化，应调 `gain_cal`，不要调 `offset_cal_v`。通常先保持为 `0`。

---

## 2. 推荐调节顺序

```text
1. 零输出：调 bias_voltage_v，使 Offset 接近0
2. 中等输出：调 gain_cal，使Vpp接近示波器
3. 多点验证：只有存在固定误差时再调 offset_cal_v
```

## 3. 其他参数

- `.input_min_v = -30.0f`：外部反馈最小电压。
- `.input_max_v = 30.0f`：外部反馈最大电压。
- `.nominal_frequency_hz = 30000.0f`：标称频率，当前为30 kHz。
- `.divider_ratio = 1.0f / 18.0f`：硬件分压比例，ADC端约为输入的1/18。
- `.adc_vref_v = 3.3f`：ADC参考电压，最好填写实测VDDA。
- `.adc_full_scale_code = 4095U`：12位ADC最大码值。
- `.sample_rate_hz = 600000U`：ADC实际采样率，当前600 kS/s。
- `.dma_buffer_length = PLASMA_FB_DMA_BUFFER_LENGTH`：一次处理的DMA样本数。
- `.feedback_to_hv_kv_per_v = 1.0f`：1 V反馈对应1 kV高压输出。
- `.bias_cal_v = 0.0f`：在`bias_voltage_v`基础上的附加偏置修正；已直接填写实测偏置时通常保持0。
- `.adc_clip_low_code = 5U`：ADC低端削顶判断阈值。
- `.adc_clip_high_code = 4090U`：ADC高端削顶判断阈值。
- `.min_valid_amplitude_v = 0.5f`：Vpp低于该值时判定为无有效信号。
- `.frequency_tolerance_hz = 3000.0f`：频率允许误差，当前约允许27~33 kHz。
